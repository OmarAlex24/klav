# Decisiones (ADR)

Cada decisión que cambia o fija el diseño va aquí como un archivo `NNNN-titulo-corto.md`. Una vez aceptado, un ADR no se edita: si la decisión cambia, se escribe uno nuevo que lo reemplace.

Única excepción: el cambio de nombre de Lacre a Klav ([0019](0019-nombre-klav.md)) renombró de forma mecánica identificadores, rutas, enlaces y el nombre del producto en los ADRs anteriores, sin cambiar ninguna decisión.

Plantilla:

```markdown
# NNNN · Título

- Estado: propuesto | aceptado | reemplazado por NNNN
- Fecha: AAAA-MM-DD

## Contexto
## Decisión
## Consecuencias
```
