Klav is an open-source password manager, encrypted end to end, built for people who work with AI agents. Agents get actions, not values: an agent can fill a login or run a command with a secret without Klav returning the secret to it. These docs are for the people who set Klav up and for the agents that read them.

Start with the section you need:

- [Overview](/overview/): what Klav is and what works today.
- [Get started](/get-started/): install Klav, create an account, import your passwords, add a device.
- [Apps](/apps/): the Mac app, the iPhone app, the browser extension and the CLI.
- [Agents](/agents/): permissions, approvals, and secrets an agent uses without seeing them.
- [Self-hosting](/self-hosting/): run your own Klav server.
- [Security](/security/): how Klav protects your data, and how to report a vulnerability.
- [Reference](/reference/): CLI commands and a glossary.
- [On the way](/on-the-way/): designs that are accepted and not built yet.
