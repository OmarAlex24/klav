This page lists where Klav will be installed from, and the server Klav will run for you, once each one is out. Until then, [Install Klav](/get-started/install/) says what to do instead. No dates.

## The browser extension in the stores

The extension will be in the Chrome Web Store, for Chrome, Brave, Edge, Arc and Dia, and on addons.mozilla.org, for Firefox.

Until then, you install it by hand, and both browsers have a cost:

- **Chromium browsers** run the build with Klav's public development key. With it, any unpacked extension that carries that key can talk to `klavd`, not only Klav's.
- **Firefox** gets an add-on file that Mozilla signs without listing it. It stays installed, but it doesn't update itself: you install each new version from klav.dev's downloads.

From the stores, the extension installs and updates like any other, and `klav extension install-host` needs no `--dev`.

## The iPhone app in the App Store

The iPhone app comes out as a beta on TestFlight first, and in the App Store later.

## Klav's own server

Every Klav app signs in to a Klav server, which keeps only encrypted data. Klav runs one at `api.klav.dev`, and today it is a free beta, by invite: request one on [klav.dev](https://klav.dev/#beta). Invites go out by hand, a few at a time, by email, with a code you use once to create your account.

What is still on the way is opening it to everyone: sign-up without an invite, and a plan of 20 USD a year, once the beta ends. Beta accounts hear about it at least 60 days before anything is charged. Then each person chooses: the plan, or moving the account to their own server with `klav account set-server`. Hosting your own server stays free.

Without an invite, you [host your own](/self-hosting/). The apps don't change: "Use my own server", or `--server` in the CLI, points them at it.
