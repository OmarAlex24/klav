<Aside>Not available yet. The pages in this section describe what is decided and not out yet.</Aside>

This section is Klav's public roadmap: features with an accepted design that are not finished, where Klav will be installed from once it is in the stores, and Klav's own server. Each page says what problem it solves and the idea behind it. It gives no dates, and nothing here appears in Get started, Apps or Agents until it ships.

- [Sandboxes with a credential proxy](/on-the-way/sandboxes/): an agent in a disposable sandbox uses your API tokens without ever holding them.
- [Environments per repository](/on-the-way/environments/): `development`, `production` and other sets of variables for a repository, imported from a `.env` once, with production behind Touch ID.
- [Deployed services](/on-the-way/deployed-services/): an app on a hosting platform keeps a service ID instead of its API keys, and Klav notices a copied instance.
- [Stores and Klav's own server](/on-the-way/stores-and-hosted-server/): the extension in the Chrome Web Store and on addons.mozilla.org, the iPhone app in the App Store, and Klav's own server open to everyone after its invite-only beta.
