This section covers what you do with each Klav app day to day, once it is installed and signed in. To install an app or sign in, see [Get started](/get-started/). What agents do through these apps is in [Agents](/agents/).

1. [The Mac app](/apps/mac/): the menu bar panel, the window, items, Touch ID, vault health and settings.
2. [The iPhone app](/apps/iphone/): items, Face ID, AutoFill for passwords, codes and passkeys, agent requests and settings.
3. [The browser extension](/apps/browser-extension/): filling logins, cards and addresses, saving and generating passwords, codes, passkeys and the popup.
4. [The command line](/apps/cli/): `klavd`, reading and editing items, codes, the generator, vault health and the trash.
